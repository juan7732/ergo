## New: install from winget

Windows users no longer have to download a `.exe` from the Releases page and
put it on PATH by hand. ergo is in the Windows Package Manager community
repository as `juan7732.ergo`:

```powershell
winget install juan7732.ergo
winget upgrade juan7732.ergo
```

The package is portable: no installer, and `ergo` lands on your PATH. Every
tagged release submits an updated manifest to `microsoft/winget-pkgs`
automatically, so new versions show up there a few days after the GitHub
release. `ergo update` does not yet recognize a winget-managed install, so use
`winget upgrade` on Windows for now
([#7](https://github.com/juan7732/ergo/issues/7)).
