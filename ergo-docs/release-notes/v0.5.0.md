# ergo v0.5.0

Released: 2026-09-03

Adds the first read verb that spans every workspace at once. Upgrade with
`brew upgrade ergo` or `ergo update`.

## New: `ergo search` finds a repo across all your workspaces

"Do I already have this repo pulled somewhere?" used to mean grepping
`~/.ergo/workspaces/*.toml` by hand, and the question got harder with every
workspace you added. One command now answers it completely:

```sh
ergo search ergo
```

```
┌────────────────┬───────────┬────────────────┬───────┬──────┬────────────┐
│ Workspace      │ Kind      │ Name           │ Group │ Tags │ State      │
├────────────────┼───────────┼────────────────┼───────┼──────┼────────────┤
│ ergo-ecosystem │ workspace │ ergo-ecosystem │       │      │ synced     │
│ ergo-ecosystem │ repo      │ ergo           │ core  │ go   │ cloned     │
│ platform       │ repo      │ ergo           │       │      │ uncloned   │
└────────────────┴───────────┴────────────────┴───────┴──────┴────────────┘
```

- Matches a case-insensitive substring of repo names and URLs, folder names,
  and workspace names, across every configured workspace.
- `State` tells you whether the hit is actually on disk: `cloned` or
  `uncloned` for repos, `created` or `not created` for folders, `synced` or
  `not synced` for workspaces. Only TOML files and directory entries are read;
  no git, no network.
- No hits prints `no matches for "<query>"` and exits 0. A broken workspace
  TOML is skipped with a warning on stderr rather than hiding hits elsewhere.

`--json` ships from day one, so agents and tooling can ask "where does repo X
live?" and get an absolute path back without re-deriving the workspace root:

```sh
ergo search ergo --json | jq -r '.results[] | select(.kind == "repo") | .path'
```

```json
{
  "query": "ergo",
  "results": [
    {
      "workspace": "ergo-ecosystem",
      "kind": "repo",
      "name": "ergo",
      "url": "https://github.com/juan7732/ergo.git",
      "group": "core",
      "tags": ["go"],
      "cloned": true,
      "path": "/Users/me/ergo-workspaces/ergo-ecosystem/ergo"
    }
  ]
}
```

`kind` discriminates each result (`repo`, `folder`, `workspace`) and the
on-disk bit is named per kind (`cloned`, `created`, `synced`). Same contract
rules as the rest of the `--json` surface: one document on stdout, warnings on
stderr, additive-only schema evolution. See the JSON output contract in
`ergo-docs/03-commands.md`.

## Fixed

- Errors were printed twice on stderr (`Error: ...` on two consecutive
  lines) for every failing command. They now print once. Exit codes are
  unchanged.

## Internal

- The release pipeline now generates winget manifests (`juan7732.ergo`,
  portable, command alias `ergo`) from the existing Windows zips and opens a
  pull request against `microsoft/winget-pkgs` on every tag. The package is
  installable only after winget-pkgs moderation merges that first PR; the
  install command will be announced in the release that ships it.
