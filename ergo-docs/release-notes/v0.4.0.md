# ergo v0.4.0

Released: 2026-08-01

A small follow-up to v0.3.0 that completes the machine-readable surface for
the ergo VS Code extension, which pins **ergo >= v0.4.0** as its minimum
supported version. Upgrade with `brew upgrade ergo` or `ergo update`.

## New: `ergo config` — read a workspace's configuration

The read-only counterpart to `ergo edit`:

```sh
ergo config             # print the workspace TOML verbatim
ergo config ws --json   # the config normalized to JSON
```

The `--json` form resolves each repo's effective name (explicit `name` or
derived from the URL) and always includes `url`, `tags`, `group`, and the
`[[folders]]` list — the configuration facts that `status --json`
(observed git state) deliberately does not carry:

```json
{
  "workspace": "ml-projects",
  "repos": [
    {
      "name": "handwriting-recognition",
      "url": "https://github.com/juan/handwriting-recognition.git",
      "tags": ["ml", "python"],
      "group": "ml"
    }
  ],
  "folders": [
    { "name": "scratch", "git": false }
  ]
}
```

Same contract rules as the rest of the `--json` surface: one document on
stdout, warnings on stderr, additive-only schema evolution. See the JSON
output contract in `ergo-docs/03-commands.md`.
